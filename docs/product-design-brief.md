# UX PRINCIPLES

The product should follow these principles:

1. Artwork always comes first.
2. Bidding must be extremely easy.
3. Users should always know the current price.
4. Users should always know when the auction ends.
5. Users should never accidentally place a bid.
6. Social features should support art discovery rather than distract from it.
7. The interface should feel premium without becoming difficult to use.
8. Empty states should be beautiful.
9. Loading states should use artwork skeletons/placeholders.
10. The platform should feel alive even when there are relatively few users.
